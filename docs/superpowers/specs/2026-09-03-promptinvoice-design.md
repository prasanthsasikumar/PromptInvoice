# PromptInvoice — design

Date: 2026-09-03

## Goal
A self-hostable clone of invoala.com's free invoice generator, used to issue invoices
from several businesses (FlowsXR, Aisee, …) from one place, and shareable with partner
companies.

## Constraints / decisions
- Static site: `index.html` + `css/` + `js/`. No bundler, no server. Works from `file://`
  and from any static host (GitHub Pages, Vercel, Netlify).
- All data lives in `localStorage` (profiles, clients, invoice history, settings).
  JSON export/import provides backup and moving between machines.
- PDF = browser print-to-PDF with an A4 `@page` stylesheet (crisp, selectable text).
- AI drafting calls the Anthropic Messages API directly from the browser with a
  user-supplied key (stored locally), structured output (`output_config.format`),
  model `claude-opus-5`, server-side fallbacks `"default"`.

## Page structure (mirrors invoala)
Nav · Hero · Generator (form + live preview) · Features · How it works ·
What makes a good invoice · FAQ · Footer. Pricing/Trustpilot/newsletter omitted.

## Generator form
- AI describe box → Generate (fills form).
- Document type: Invoice / Quote / Estimate / Receipt.
- From: business profile selector (save / new / delete), name, email, address, phone,
  tax id, logo, invoice number prefix.
- Bill to: client selector (save / delete), name, email, address.
- Items: description, qty, rate, amount; add/remove.
- Currency (150+), tax % + tax label, discount (% or fixed), shipping,
  issue date, due date, invoice number (auto per profile), PO / custom fields,
  payment details, notes, accent theme.
- Actions: Download PDF (print dialog), Print, Save invoice, New, Duplicate.
- Recent invoices list (load / delete). Backup export/import.

## Modules
- `js/currencies.js` — currency table (code, name, symbol, decimals).
- `js/calc.js` — pure functions: `computeTotals`, `formatMoney`, `nextInvoiceNumber`,
  `addDays`, `formatDate`. Loaded by browser and by node tests.
- `js/storage.js` — localStorage wrapper for profiles, clients, invoices, settings.
- `js/ai.js` — Anthropic call + JSON schema.
- `js/app.js` — state, form binding, rendering of preview, actions.
- `tests/calc.test.js` — node:test for calc.js.

## Testing
`node --test tests/` for calc logic; manual browser check with headless Chrome
screenshot for layout.

## Addendum — team sign-in and public release (2026-09-03)

- **Auth/backend:** Supabase (magic-link email, Postgres, RLS). Schema in `supabase/schema.sql`.
  Credentials in `js/config.js`; empty = local mode, the Sign-in button is hidden.
- **Workspace = email domain.** `pi_ensure_company()` creates/joins the company for the caller's
  domain; public mail providers are keyed by the full email (private workspace). RLS policies
  restrict every table to `company_id = pi_company_id()`.
- **Storage layer:** `Store` keeps synchronous reads. In cloud mode it serves from an in-memory
  cache loaded at sign-in and mirrors every write to Supabase (`upsert`/`delete`, jsonb `data`).
  Draft and settings (API key) always stay in localStorage.
- **Migration:** on first sign-in to an empty workspace, offer to copy local data up.
- **Public release:** generic seed profile ("My business"), no company-specific copy,
  screenshots generated by `tests/screenshots.mjs`, GitHub Pages from `main`.
